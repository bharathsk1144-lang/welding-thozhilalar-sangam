# Image suitability checks

Registration checks JPEG, PNG, or WebP MIME type and file signature, size, decoded dimensions, image readability, aspect ratio, and sampled blur/blankness. The server repeats file, decode, dimension, and basic quality checks before protected storage. Accepted documents start in **Needs review**; an authorized admin can accept them or request a correction. Replacements and review actions are audited.

The browser runs a same-origin MediaPipe face detector on passport photos to detect multiple faces and estimate face size and position. It warns about unusually saturated colors, low detail, and busy edges. Aadhaar images are inspected with the same face detector and a same-origin Tesseract OCR worker. OCR looks for document-category words such as `AADHAAR`, `UIDAI`, and unmistakable unrelated labels such as `PAN CARD`; recognized text is used only in memory for this decision. Full Aadhaar numbers and OCR text are never sent to an external model service or logged. Both models and their runtime files are served by this application.

These are suitability checks, not identity authentication. A face detector can miss a face or group, especially with small, rotated, occluded, or heavily filtered faces. OCR can miss text on Tamil-only, low-resolution, cropped, or reflective documents. A legitimate e-Aadhaar screenshot is not rejected merely because it is electronic. Uncertain images remain for authorized admin review. A client can also bypass browser checks, so server validation and admin review remain necessary. The local browser model may be slow on older phones; if it cannot run, the upload receives guidance and admin review rather than an unsupported claim of automated verification.

Runtime assets are pinned in `client/package-lock.json` and copied into `client/public/vision` and `client/public/ocr` for same-origin delivery: [MediaPipe Tasks Vision](https://github.com/google-ai-edge/mediapipe) (Apache-2.0), [Tesseract.js and its core](https://github.com/naptha/tesseract.js) (Apache-2.0), and [English language data](https://www.npmjs.com/package/@tesseract.js-data/eng) (MIT). The face model is Google's published BlazeFace short-range model. No runtime CDN or third-party image processing endpoint is configured.
